# User documentation

For readers of the book. These pages are about getting the book in front of you and finding your way around it; the subject matter itself is in [`book/`](../../book/README.md).

| Page | Read it when |
|------|--------------|
| [Quick start](quick-start.md) | You have just arrived and want to start reading |
| [Concepts](concepts.md) | You want to know how the book is organised before you commit time to it |
| [Usage](usage.md) | You want to read offline, choose a viewer, or validate a copy |
| [Troubleshooting](troubleshooting.md) | A diagram shows as code, a link is dead, or a check fails |
| [Command reference](reference/commands.md) | You need the exact `make` target or checker flag |

## The short version

1. Open [`book/README.md`](../../book/README.md).
2. Use its "Who this is for" table to choose a starting chapter.
3. Read in any Markdown viewer that renders Mermaid. GitHub works with no setup.
